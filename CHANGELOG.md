## [0.1.0] — 2026-08-24

### Added
- `MetagenomicsAdapter` (`api_version=1`), registered on the `indicium.adapters` entry point.
  Declares `domain_id` / `primary_domain` = `metagenomics`, 26 snake_case domain qualifiers, and
  the prefix map needed to expand metagenomics CURIEs (`NCBITaxon`, `ENVO`, `OBI`, `GO`, `Pfam`,
  `KEGG`, `edam`, `MIxS`, `ENA`, `SRA`, `MGnify`, `IMG`).
- EDAM concept enrichment. `enrich_claim` attaches an `edam:` CURIE to any `subject` / `object` /
  `qualifier` slot naming an EDAM concept, with a `semapv:LexicalMatching` justification. Pure:
  returns a new dict and never overwrites a term another adapter has set.
- Vendored EDAM index cut from four roots — Metagenomics, Metagenomic sequencing, Microbial
  ecology and Metatranscriptomics — regenerated by `data/build_edam_index.py`, which records why
  each of the latter three has to be named explicitly (none is reachable by walking down from
  the Metagenomics topic itself).
- `subdomains` derived from the same EDAM walk, so the classification vocabulary cannot drift
  from the labels enrichment resolves against.
- `techniques` (16, curated): EDAM models assays as operations and data rather than as a
  technique hierarchy for this domain, so there is nothing to derive them from.
- `ontology_terms_unmatched`: slots that carried text but resolved to nothing, so a miss stays
  distinguishable from "not attempted".

### Deliberately not included
- **Accession recognition.** Under ADR 0001 the canonical accession table in `asb-domain-core`
  owns those patterns; the MGnify, ENA/SRA and IMG accession families live there. A test greps
  this package's own source and fails if an accession shape appears.
- **Assembler, binner or organism keyword tables.** Those are extraction heuristics, not a
  controlled vocabulary this tier owns.

### Known limitations
- Matching is exact after case-folding and whitespace collapse, so a paraphrase does not
  resolve. Substring or fuzzy matching over an ontology produces confident wrong CURIEs, and a
  wrong identifier is worse than none.
- EDAM's own Metagenomics-adjacent topics are shallow: the four-root walk currently yields a
  small index (four subdomains). This is what EDAM actually carries for the domain, not a
  curation shortfall — a hand-added label would be the wrong-CURIE failure the package exists to
  avoid.
